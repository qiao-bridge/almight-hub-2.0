# almight-hub-2.0

#### Description
在面对普通场景下（键鼠、打印机、tf卡等）usb2.0的使用更加频繁，传统的usb2.0的hub包括功能单一，并不能应对更加复杂的场景。因此有了该项目基于SL2.1的全能型hub能更好的应对接口扩展与转化、读取tf卡、串口的实现，更加重要的是其制作成本不到6元。
