# almight-hub-2.0

#### 介绍
在面对普通场景下（键鼠、打印机、tf卡等）usb2.0的使用更加频繁，传统的usb2.0的hub包括功能单一，并不能应对更加复杂的场景。因此有了该项目基于SL2.1的全能型hub能更好的应对接口扩展与转化、读取tf卡、串口的实现，更加重要的是其制作成本不到6元。

#### 软件架构
本项目仅为硬件+外壳的一体化设计，硬件设计使用嘉立创eda专业版，外壳设计使用Fusion360。


#### 安装教程

1.  若“直接使用”可以跳过安装教程，直接将Gerber、stl直接发给工厂。
2.  若“自己要进行修改”，板子设计使用的是嘉立创eda专业版、外壳设计使用的是Fusion360。嘉立创开源地址：https://oshwhub.com/qiao_wen/almight-hub-20

#### 使用说明

1.  直接使用
2.  自己修改
